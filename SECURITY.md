# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security issue in QuartzNotch, use GitHub’s private vulnerability reporting for this repository if available:

https://github.com/Clayton630/QuartzNotch/security/advisories/new

If private reporting is not available, contact the maintainer privately before disclosing details publicly.

When reporting a vulnerability, please include:

- A clear description of the issue.
- Steps to reproduce it.
- The affected QuartzNotch version or commit.
- Your macOS version and Mac model.
- Any relevant logs, screenshots, or proof-of-concept details.

Security issues in third-party dependencies should also be reported to the maintainers of those dependencies.
